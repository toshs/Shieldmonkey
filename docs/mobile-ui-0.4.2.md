# モバイル UI 0.4.2

- トグルを共通化。44px のタップ領域と固定のトラック寸法を使い、つまみの移動量をトラック幅から計算します。スマホ一覧だけ幅を縮める指定と、チェックボックスのサイズが隠し入力に混ざる指定を除きました。
- ポップアップの独自 SVG パスを Lucide のアイコンに統一。`scripts/sync-popup-icons.mjs` で静的なノードを生成するため、ポップアップに React を読み込ませる必要はありません。
- スマホ一覧から「その他」を取り除き、編集・移動・削除・更新をカードに直接表示。作成・貼り付け・読み込みは上部の3ボタンにまとめ、検索・絞り込み・選択も直接操作できます。
- ポップアップの有効状態を別の行へ分け、空の状態は高さ250px、一覧は件数に合わせた高さに調整。スマホの行には有効切替と編集を配置し、削除・更新は管理画面から操作できます。
- タッチ端末の横画面でもスマホ用レイアウトを維持。操作欄を2段にまとめ、一覧は2列、下部ナビは48pxに調整します。

## 検証

Android 15 / Vivaldi 8.3.4192.64 の実行中の拡張で確認しました。

- 幅320・390・430px、100%・125%の文字、明暗テーマでトグルのつまみが枠内に収まり、操作ボタンの高さ44pxと横はみ出しがないことを確認。
- 幅914pxの横画面でスマホ表示、1280pxでデスクトップの表を維持。
- スクリプトの有効・無効の保存、移動ダイアログ、削除確認、一括選択とキャンセルを確認。
- 通常版・Vivaldi版ビルド、TypeScript、ESLint、既存単体テスト44件を確認。

配布 ZIP は毎回 `Shieldmonkey-vivaldi.zip` とし、直下に `manifest.json` を置きます。更新時は現在 Vivaldi が読み込んでいるフォルダーの名前・場所を変えず、中身を上書きして既存の拡張機能を再読み込みします。読み込み先の名前に旧バージョン番号が入っていても改名しません。詳しい手順は [更新手順](vivaldi-update-ja.txt) を参照してください。
