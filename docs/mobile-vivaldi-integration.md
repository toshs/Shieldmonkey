# Android Vivaldi 作業の統合

取り込み元は個人フォークの次の2ブランチです。

- `feature/mobile-vivaldi-workspace`（`62e2ae1`）: 軽量ポップアップ、スマホの編集ツールバー、フォルダー移動、外部ファイルとの同期、競合確認、保存履歴と復元、Vivaldi 用ビルド。
- `fix/desktop-mobile-backup`（`64b4b3b`）: 保存・有効化失敗時の既存登録の保護、未保存編集の画面遷移確認、JSON 復元のプレビューと復旧用書き出し、一括選択と URL 判定の修正。

今回のポップアップ修正は軽量版に移植しました。明示的なサイズを維持し、タブの利用可能な高さに合わせて横画面のはみ出しを防ぎます。バージョンは `0.4.1` です。

フォルダー保存はワークスペースの競合確認付きキューを使用し、JSON 自動ダウンロードはバックグラウンドで直列に処理します。旧 `shieldmonkey_dump.json` は設定から JSON として読み込み、新しい空のワークスペースフォルダーへ移行できます。

## 確認結果

- TypeScript・通常版ビルド・Vivaldi 版ビルド・ESLint: 成功。
- 単体テスト: 7ファイル、44件成功。
- Android 15 / Vivaldi 8.3.4192.64: 下部の拡張メニューから開いた実ポップアップで、縦画面 360×400、横画面 360×263 と操作ボタンの表示を確認。
- 同環境で、不正な保存を拒否した後に元のコードと登録が保持されること、編集画面の描画、未保存の画面遷移確認、JSON 復元プレビューとキャンセルを確認。
- 既存の Chromium E2E スイートは、このホストでサービスワーカーの起動待ちがタイムアウトするため完走していません。上記の Android 確認は別途実施しています。
