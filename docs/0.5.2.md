# 0.5.2: 通知クリックとオリジン境界

ユーザースクリプトの通知クリックで、一律に管理画面を開く処理を削除しました。クリック時は通知元のタブを前面にし、元の隔離環境で onclick を実行します。指定 URL を開く場合は、次の制約をすべて満たす必要があります。

- URL は HTTP / HTTPS、通知元とスキーム・ホスト・ポートが一致し、承認済みスクリプトの対象範囲内であること。ユーザー情報付き URL、内部ページ、javascript:、data:、file: などは拒否します。
- URL を指定できるのはトップフレームだけです。別タブを URL や番号で探したり、既存タブの URL を書き換えたりしません。移動先は opener を指定しない新規タブです。
- 通知元は、ブラウザーが示すタブ・フレーム・文書 ID・オリジンと、スクリプト ID・現在のトークンに結び付けます。スクリプトから渡されたタブ番号やオリジンは出所として使用しません。
- 作成・クリック・応答・完了時に現在の状態を再検証します。ページが別文書になった場合、対象範囲を離れた場合、無効化・権限取り消し・コード変更でトークンが変わった場合、古い通知は権限を引き継ぎません。
- onclick は専用ポートで元の隔離環境だけに送り、クリックごとの nonce と通知元の実行環境を照合します。同じスクリプト・同じトークンでも、別オリジンのポートから応答できません。preventDefault()、例外、応答タイムアウトで URL を開く動作を中止します。

通知の見出しには、拡張側で求めた通知元オリジンとスクリプト名を表示します。外部 URL のアイコン取得は行わず、対応する data: 画像以外は拡張のアイコンを使います。通知数・文字数・画像サイズを制限しています。

## バックグラウンド処理の再起動

通知の対応情報は Web サイトのストレージではなく、拡張専用の storage.session に保存します。文書 ID がある場合のみ復帰対象とし、現在の文書・承認状態を再検証します。コールバックは同じ文書の同じスクリプトが専用ポートへ再接続した場合だけ配送します。文書 ID が得られない環境では、ワーカーをまたいで復帰しません。

クリックの対応情報は、副作用より先に一時領域から消費します。ワーカーが途中で再起動しても古いクリックを再実行しません。出所の分からない古い通知も復帰させません。通知の対応情報はバックアップ・エクスポートに含めず、ブラウザー終了をまたぐ再実行は行いません。通知の最大保持期間は 24 時間です。

## API と境界

GM_notification の文字列形式（4 番目の引数が onclick）、details 形式、ondone、url、timeout に対応します。GM.notification はクリックの有無を Promise<boolean> で返します。preventDefault() は onclick の同期処理中に呼んでください。source が失効したときは、古いコールバックを別の文書に配送しません。すべての Tampermonkey オプションに対応するものではありません。

この制限は、通知を経由する拡張権限の使い方を制御するものです。onclick は元のスクリプトの権限のままであり、別途承認済みの GM_openInTab や通常の Web API に新しい権限を付与しません。最初の URL の検証後に起きる通常の HTTP リダイレクトまで固定するものでもありません。遷移先でのスクリプト実行・GM 権限は、その文書で改めて既存のスコープと認証に従います。

参考: [Chrome notifications](https://developer.chrome.com/docs/extensions/reference/api/notifications)、[MessageSender の文書情報](https://developer.chrome.com/docs/extensions/reference/api/runtime#type-MessageSender)、[Tampermonkey の通知 API](https://www.tampermonkey.net/documentation.php?q=GM_notification)。
