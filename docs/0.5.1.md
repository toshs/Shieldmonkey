# 0.5.1: モバイル表示とフォルダーの再接続

設定・ヘルプ画面の末尾が下部タブバーに隠れる問題を修正しました。画面本体を実際の表示領域に合わせ、タブバーの分を除いた領域だけでスクロールします。縦画面・横画面ともに末尾に余白を確保します。

選択した作業フォルダーは IndexedDB に保存し、同じ画面内では同じハンドルを再利用します。別の管理タブでフォルダーが変更された場合は保存先を読み直します。永続許可に対応する環境では、保存済みのアクセス権を復帰させます。画面を開いた操作の直後は、その操作状態が終わってから復帰を試します。

一時許可が失効した場合は、設定またはスクリプト一覧の「再接続」を押してください。保存済みフォルダーへの許可を直接求めるため、フォルダーの選び直しは不要です。別の作業領域の場合に必要な「復元」の確認は維持します。

## Android Vivaldi の制約

Android 15 / Vivaldi 8.3.4192.64 の実際の許可画面に、編集許可は「このサイトのタブをすべて閉じるまで」と表示されました。すべての管理タブを閉じた後、保存済みフォルダーハンドル自体は保持されますが、編集許可は prompt に戻ることを確認しています。この環境では、ブラウザーの確認を再接続時に許可する必要があります。拡張機能から永続許可へ変更する API はありません。

[Chromium の永続許可の説明](https://developer.chrome.com/blog/persistent-permissions-for-the-file-system-access-api)にある「毎回のアクセスを許可」が表示される環境では、それを選ぶと再確認を減らせます。対応していないブラウザーに、拡張機能からこの選択肢を追加することはできません。

## 更新

ZIP 名は引き続き `Shieldmonkey-vivaldi.zip`、直下に manifest.json を置きます。既存の読み込み先の名前・場所は変えず、内容を上書きして既存の拡張機能を再読み込みしてください。削除して再インストールする必要はありません。
